# Encrypted Notepad

A secure encrypted notepad with Monaco editor, built with Electron.

## Features

- Secure AES encryption for your notes
- Monaco editor (VS Code's editor)
- Custom `.etxt` file format for encrypted text files
- Cross-platform support (Windows, macOS, Linux)

## Installation

```bash
npm install
```

## Usage

```bash
# Development
npm run dev

# Production
npm start
```

## Building

```bash
# Windows portable
npm run build:win

# Windows installer
npm run build:win:installer

# macOS
npm run build:mac

# Linux
npm run build:linux

# All platforms
npm run build:all
```
